# SESSION_LOG 작성 규칙

SESSION_LOG의 "구현 요약"은 다음 세션의 유일한 컨텍스트다. 불완전하면 다음 세션이 실패한다.

## "구현 요약" 필수 항목
- **주요 클래스/함수**: 반드시 전체 경로 포함. `IntentAnalyzer` (X) → `packages/backend/src/interpreter/intent_analyzer.py::IntentAnalyzer` (O).
- **계약 대비 변경점**: contracts와 실제 구현이 다른 부분. 없으면 "없음" 명시.
- **환경변수**: 새로 추가한 환경변수와 기본값. `.env.example` 반영 여부.
- **의존 모듈 사용**: 다른 모듈의 인터페이스를 사용했으면 어떤 것을 어떻게.

## "다음 세션에 알려줄 것" 기준
- **왜** 미완성인지, **어떻게** 이어갈 수 있는지 포함할 것.
- 발견된 이슈는 재현 조건 포함.
- 다음 세션에서 읽어야 할 추가 문서가 있으면 명시.

## 금지
- "잘 됨", "정상 작동" 같은 모호한 표현. 구체적 테스트 결과(통과/실패 수)로.
- 변경된 파일 목록 누락. `git diff --name-only`로 확인.
