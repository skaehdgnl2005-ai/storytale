# 보안 규칙

## 아동 데이터 보호 (최우선)
- 아이 사진은 캐릭터 시트 생성 후 즉시 삭제. 원본 저장 금지.
- 사진 해시만 보관 (중복 생성 방지용).
- 아이 이름, 나이, 프로필 정보는 암호화 저장 (AES-256).
- 로그에 아이 이름/개인정보 절대 출력 금지. 로깅 시 `child_id`만 사용.
- 외부 API(Claude, Replicate) 호출 시 아이 사진 메타데이터 제거.
- 사진 업로드 제한: 최대 5MB, JPEG/PNG만 허용, EXIF 메타데이터 자동 제거.

## 인증/인가
- JWT: 만료 24시간. 리프레시 토큰 7일.
- 본인 리소스만 접근 가능. 모든 API에 소유자 검증.

## API 보안
- CORS: 모바일 앱 도메인만 허용.
- Rate limiting: 스토리 생성 10회/시간/사용자. Redis 기반.
- 입력 검증: Pydantic 모델로 모든 입력 검증. SQL 인젝션은 ORM이 방어.
- 부모 서술형 입력: 최대 500자 제한. HTML 태그 스트립.

## LLM 안전
- 부모 입력이 LLM 프롬프트 인젝션으로 사용될 가능성 차단.
  - 부모 입력은 user 메시지에만 배치. system 프롬프트에 삽입 금지.
  - 출력 JSON 스키마 검증 필수. 스키마 불일치 시 재생성.
- 생성된 스토리 텍스트 후처리 검증:
  - 금지어 필터 (폭력, 성적 표현, 비속어).
  - 아이 실명이 텍스트에 포함되었는지 확인 (의도된 개인화와 구분).

## 시크릿 관리
- API 키: 환경변수. 코드에 하드코딩 절대 금지.
- .env 파일: .gitignore 필수. .env.example만 커밋.
- 프로덕션: Railway 환경변수 또는 시크릿 매니저.

## 데이터 보존/삭제 정책
- 탈퇴 시 30일 이내 전체 데이터 삭제 (User, ChildProfile, Story, 캐릭터 시트).
- 캐릭터 시트는 마지막 사용 후 90일 보존. 이후 자동 삭제.
