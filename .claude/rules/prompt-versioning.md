# LLM 프롬프트 버전 관리 규칙

`docs/prompts/` 내의 모든 `.md` 파일에 적용.

## 버전 체계
- 파일명에 메이저 버전 포함: `{name}-v{major}.md` (예: `intent-analyzer-v1.md`).
- **Minor** 변경 (파라미터 조정, 문구 수정): 파일 내 `## 변경 이력`에 기록.
- **Major** 변경 (출력 스키마 변경, 구조 재설계): 새 파일 생성 (`v1` → `v2`).

## 수정 시 필수 절차
1. 변경 전: 현재 버전의 테스트 결과를 기준선으로 기록.
2. 프롬프트 수정 + `## 변경 이력`에 날짜·변경 내용·변경 이유 추가.
3. 동일 입력으로 테스트 재실행. 기준선과 비교.
4. SESSION_LOG에 "프롬프트 변경 이력" 섹션 작성.

## 프롬프트 내 필수 섹션
- **권장 LLM 파라미터**: temperature, max_tokens. JSON 응답 프롬프트는 `temperature: 0.3`, 텍스트 생성은 `0.7~0.8`.
- **입력 변수**: `{{variable}}` 형식으로 명시.
- **출력 스키마**: JSON 응답인 경우 정확한 스키마.

## 변경 이력 형식
```
## 변경 이력
- v1.1 (2026-04-07): 권장 LLM 파라미터 추가. 이유: JSON 응답 안정성 위해 temperature 0.3 권장.
- v1 (2026-04-01): 초기 버전.
```
