```
ScenePlanSafetyError: 장면 'cake_making_2'의 description에 금지 키워드 '죽이'가 포함되어 있습니다.
```

**로그 요약:**
```
WARNING plan_revise safety_retry attempt=1/2 reason=장면 'cake_making_2'에 금지 키워드 '죽이'
WARNING plan_revise safety_retry attempt=2/2 reason=장면 'cake_making_2'에 금지 키워드 '죽을'
→ 2회 재시도 한도 초과 → ScenePlanSafetyError 발생
```

**원인 분석: `safety-rails.json` 금지어 오탐**

케이크 만드는 장면에서 LLM이 생성한 "케이크 **반죽이** 뭉쳐졌어요" 류 표현에 `'죽이'`가 포함되어 트리거됨. 재시도 2회에서 `'죽을'` 포함 표현도 나와 계속 실패.

`safety-rails.json`의 `content_filter_keywords`에는 이미 주석이 있음:
> "문맥에 따라 허용되는 경우도 있으므로 키워드 검출 후 LLM으로 2차 판단 권장"

`guardrail-editing.md`에도 이 오탐 위험이 명시되어 있음:
> "새 금지어 추가 시 오탐 검토 ('죽' → '미역죽' 오탐 가능)"

**해결 방향:** `'죽이'` 단독 키워드를 의도한 활용형(`'죽이고'`, `'죽이는'`, `'죽이자'`)으로 교체하거나, 전후 공백/단어 경계를 포함한 패턴 매칭으로 변경.

## 발견된 이슈

### 이슈1 — `죽이` 금지어 오탐 (심각도: **높음**)

- **재현 조건:** 케이크/빵 만들기 관련 장면 생성 시 "반죽이" 표현 사용 시 트리거
- **영향 범위:** `celebration` 카테고리의 음식 관련 장면 전반, `plan_reviser.py`의 safety 검증
- **위치:** `docs/guardrail-seeds/safety-rails.json` → `content_filter_keywords.keywords`의 `"죽이"`
- **수정 방향:** `"죽이"` → `"죽이고"`, `"죽이는"`, `"죽이자"` 등 의도한 활용형으로 교체

### 이슈2 — Gemini 빈 응답 처리 불충분 (심각도: **중간**)

- **재현 조건:** Gemini fallback 사용 시 (`GEMINI_API_KEY` 설정), 특정 프롬프트에서 `response.text = None`
- **영향 범위:** Claude 서버 장애 시 fallback 전체 비작동
- **위치:** `packages/backend/src/storytale/interpreter/gemini_provider.py:128`
- **수정 방향:** Gemini 안전 필터 차단 여부 확인 후 프롬프트 개선 또는 재시도 로직 강화

### 이슈3 — Claude 타임아웃 시 Gemini 2차 호출 빈 응답 (심각도: **중간**)

- **재현 조건:** Claude 타임아웃 → Gemini fallback 1차 성공 → safety retry → Claude 재타임아웃 → Gemini 2차 호출
- **영향 범위:** 네트워크 불안정 환경에서 cascading failure
- **위치:** `llm_client.py` + `gemini_provider.py` 연동 로직
- **수정 방향:** safety retry 시에도 fallback 체인 유지 보장, 또는 Gemini 2차 호출 시 별도 재시도 로직
